# Chrome Web Store 发布清单

## GitHub 与公开页面

- [x] 确定开发者公开名称和支持渠道
- [x] 将项目发布到 GitHub
- [x] 配置从 `main` 分支的 `/docs` 目录发布 GitHub Pages
- [ ] 打开隐私政策公开网址，确认无需登录即可访问

## 开发者账号

- [ ] 注册 Chrome Web Store 开发者账号并支付一次性注册费
- [ ] 验证开发者联系邮箱
- [ ] 为开发者 Google 账号启用两步验证

## 上传前检查

- [ ] 在干净的 Chrome 用户资料中加载已解压扩展
- [ ] 测试手动粘贴和“从剪贴板读取”
- [ ] 测试常见邀请、缺少结束时间和跨日会议
- [ ] 测试“账号 1”和“账号 2”的目标账号选择
- [ ] 确认 Google Calendar 页面中的标题、时间、时区、链接和会议号正确
- [ ] 确认所有商店截图均使用虚构会议号和账号名称
- [ ] 运行 `npm test`
- [ ] 确认上传 ZIP 根目录直接包含 `manifest.json`

## 开发者后台

- [ ] 上传 `release/tmi-to-gcal-v1.2.0-store.zip`
- [ ] 粘贴 `listing-zh-CN.md` 中的商品详情
- [ ] 上传 128×128 图标、三张 1280×800 截图和 440×280 小型宣传图
- [ ] 填写 `privacy-form-zh-CN.md` 中的单一用途、权限理由和数据披露
- [ ] 选择“不使用远程代码”
- [ ] 填写公开隐私政策 URL
- [ ] 添加主页和支持 URL
- [ ] 首次建议选择“不公开”进行商店安装测试
- [ ] 提交审核

## 审核通过后

- [ ] 从 Chrome Web Store 安装并完成一次真实流程测试
- [ ] 确认公开范围和发布地区
- [ ] 准备公开发布时再切换为“公开”
- [ ] 后续更新时提高 `manifest.json` 和 `package.json` 的版本号
